# Luka合同验收：只用Foxglove GUI

需要安装cn.18或更新的当前中文版客户端。远端GUI管理器必须在线；断联时“开始案例”禁用。

## 用户操作

1. 在Foxglove布局菜单导入 `acceptance/Luka_合同验收_GUI.json`。
2. 数据连接选择Foxglove WebSocket，地址填 `ws://192.168.3.150:8765`。
3. 默认从01开始；右侧选择案例编号，显示该项合同原文，左侧自动换为对应测量面板。
4. 点击“开始案例”，后端自动调用对应ROS launch或节点；等待GUI状态和真实数据。启动不会自动发送运动目标。
5. 使用原生方向、位姿、巡检、Home或任务按钮演示。“本案例步骤”给出观察项与缺口。
6. 点击“停止案例”，等待停止确认，再开始下一项。
7. 勾选或取消“已验收”，点击“记录”；结束点击“导出全部记录”下载JSON。

无需PowerShell、SSH终端、旧网页或先在机器人执行demo命令。

雷达：以透视3D扫描图为主；显示真实LaserScan平面。相机：RGB和深度图。IMU/底盘：曲线。导航/建图/定位/避障：地图与扫描/路径。

01/02：独立底盘手动验收，只启动底盘节点；方向按钮直接发布/cmd_vel，不启动或等待雷达。保留暂停、编码器/通信健康、速度上限和松手/超时停车。此模式没有雷达碰撞保护。

03：勾选“融合EKF”再开始，管理器自动复用/准备轮里程计。
04/09：自动复用或启动受保护底盘；按住原生方向按钮移动，松开停车。
10：09导出地图完成后停止，选择10并从GUI地图列表选保存的RTAB-Map .db，再开始。
12/13/15：3D发布位姿先暂存，再点击执行；依然经过Nav2和底盘门控。
14：3D发布话题设为/patrol/add_pose加点，再执行巡检。
16/18/19/21没有已实现运行链，开始按钮禁用；可查看缺口并记录阻塞。26/27是交付/服务附录。

验收状态由你选择；软件不会因节点启动或按钮响应自动勾选。记录仅含编号、项目、是否已验收和时间。

## RTAB-Map已有地图初始定位

停止当前建图案例，等待停止确认，选择“已有地图定位（10）”或11、保存的 RTAB-Map .db，再开始。
10/11 的 3D 工具默认是“Publish pose estimate（位姿估计）”，发送 /initialpose；从实际车身位置拖向车头方向。
YAML/PGM 仅是二维栅格导出，不是RTAB-Map定位数据库；旧AMCL测试不计入RTAB-Map验收。

必须显示“RTAB-Map初始定位已验证”才可导航。核验要求真实匹配数据库中的旧节点（至少20视觉内点）、合理协方差、三轮后端更新、RGB-D/里程计新鲜、地图唯一发布者与一致的新鲜TF。
重新设置位姿即撤销许可，等待重新匹配；人工确认或已发送位姿不能替代定位成功。
原始数据库通过SQLite备份复制到运行目录后使用；不覆写原图。无数据库或未匹配时保持导航关闭。
定位心跳超过0.6秒、输入/TF过期或不一致会关闭导航许可并取消活动请求。所有控制仍经过原有底盘安全门。

记录保存在当前布局配置；导出JSON用于留档。切换内置案例会携带已经保存的记录；另行导入一个全新布局不会合并旧记录，先导出。

## 部署说明（由维护者执行，用户日常不需要）

远端节点：src/examples/contract_demo/_shared/gui_launcher.py。
服务：luka-contract-gui.service，开机仅注册案例控制与状态接口，不启动硬件。
管理器复用现有runner/ROS launch及设备所有权检查；不接受任意shell命令，不发布底盘速度。
停止仅处理本管理器启动的进程；借用的生产服务保留。导航/底盘可用时先请求暂停并用新鲜轮速确认停稳，失败会保留状态并拒绝直接切换。
启动/停止失败原因直接显示；原始日志默认折叠在“运行日志”，按完整UTF-8行显示。暂停请求独立于串口队列，关闭软件门控后仍须用新鲜轮速确认停稳。

## 地图模式

优先使用09持续建图，显示实时/map；不会用离线预览图作为定位基准。模式入口“持续建图（09）”和“已有地图定位（10）”只选择对应界面；先停止当前案例并等待停稳，再选择模式和点击开始。已有地图模式可选择保存的RTAB-Map .db；AMCL需要在3D中设置并核验初始位姿。地图/TF所有者冲突仍由现有launch拒绝，两个模式不同时运行。
